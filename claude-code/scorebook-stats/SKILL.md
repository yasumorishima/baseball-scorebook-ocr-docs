# スコアブックから成績を登録する（ひな形）

草野球チームの手書きのスコアブックから成績を登録するための、Claude Code のスキルのひな形です。`<…>` のところを自分のチームに合わせて書き換えて使ってください。手順の考え方は [stats-from-scorebook.md](../../stats-from-scorebook.md)、記号の読み方は [notation.md](../../notation.md) にあります。

## 0. チームの決め事（ここを書き換える）

- 試合の長さ：<7 回制>
- 勝ち投手：<最後に勝ち越した時点で投げていた投手。公認野球規則の「先発 5 回以上」は使わない>
- 負け投手：<公認野球規則どおり>
- 時間切れで途中で終わった回の投球回：<担当者に聞く>
- 投手の率：<失点 × 7 ÷ 投球回>
- 結果の記号：<○ ● △>
- データベースへの書き込み方：<例：SQL を担当者の確認後に実行するスクリプト。鍵はこのリポジトリにも会話にも書かない>

## 1. 受け取る

- 写真 2 枚（自軍のシート・相手のシート）と、担当者の一言（日付、紙に書いていない補足）。
- 予定表があれば、その日の相手・会場・試合の種類を引く。**紙と予定表で分かることは聞かない。**

## 2. 向きをそろえて、拡大して読む

- 縦長なら横長に回す。上下は、回ごとの得点の欄や見出しのある側が上。
- 全体 → 回の列 → 1 マスの順に、切り出して 2〜4 倍に拡大して読む（例：Python の Pillow で `Image.open(p).rotate(-90, expand=True).crop((x0, y0, x1, y1)).resize(...)`）。全体のままでは小さい記号を取り違える。
- 読む順：回ごとの得点の欄 → 打順と名前（1 つの欄に 2 人なら上が先発）→ 回の列を上から 1 打席ずつ。
- 打撃は自軍のシートから、投手の成績は相手のシートから取る（被安打・奪三振・与四死球は相手の打撃として書かれている）。

## 3. 検算する（合わなければ読み直す）

- 回ごとの得点の和 ＝ 試合の得点
- 打席数 ＝ アウト ＋ 得点 ＋ 残塁（回ごとにも、試合全体でも。タイブレークで置かれた走者は除く）
- 打数 ＝ 打席数 − 四死球 − 犠打・犠飛 − 打撃妨害での出塁
- 交代した枠：先発と途中出場の打席数の和 ＝ その枠の打席数
- 投手の失点の合計 ＝ 相手の得点、投手ごとの対戦打者の和 ＝ 相手シートの打席数
- 記号の形で迷ったら「1 回のアウトは 3 つ」で決める（時間切れ・サヨナラの回を除く）。

## 4. 表にして見せ、紙で決まらない点だけ聞く

- 打撃（打順・出場順・打席・打数・安打・打点・四死球・三振・盗塁…）と投手（登板順・回・投球回・失点・被安打・奪三振・与四死球・勝敗）を表にして担当者に見せる。
- 聞くのは紙で決まらない点だけ：同じ名字の選手が誰か、投手を交代した回、時間切れの回の扱い。
- 推して決めた点（打点・内野安打か野手選択か など）は、そうと分かるように書く。
- **担当者の「登録してよい」をもらうまで書き込まない。**

## 5. 書き込んで、読み返す

- 結果・打撃・投手は 1 回でまとめて書く（途中で止まったときに半端な状態を残さない）。
- 書いたあとに合計（打席・安打・四死球・失点）を読み返し、検算の数と一致するか確かめる。
- 推して決めた点・担当者に決めてもらった点・その理由は、成績のメモ欄に残す。
- スコアブックの画像も保存する（向きをそろえてから）。

## 6. 画面で確かめて、決め事を残す

- サイトの試合のページに結果と成績が出ているかを、画面で確かめる。ログインが要る部分は担当者に見てもらい、見ていないことは「未確認」と書く。
- 担当者に直された決め事は、この SKILL.md の「0. チームの決め事」に書き足す。次の試合から同じ間違いをしない。
